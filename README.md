# FocusTasks

**Clean & modern task manager** that lives entirely in your browser.

No accounts. No backend. Just open and organize.

### Features

- Add, complete and delete tasks
- Filter by All / Active / Completed
- Persistent storage with `localStorage`
- Clean dark UI
- Fully responsive
- Zero dependencies

### How to run

1. Clone the repository
2. Open `index.html` in any modern browser

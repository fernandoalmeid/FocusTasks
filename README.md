# FocusTasks

A clean, modern task manager that lives entirely in your browser.

No accounts. No backend. Just open the page and start organizing.

![HTML](https://img.shields.io/badge/HTML-5-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-F7DF1E?logo=javascript&logoColor=black)

## Features

- Add, complete and delete tasks
- Filter by All / Active / Completed
- Persistent storage with `localStorage`
- Clean dark UI
- Fully responsive
- Zero dependencies

## How to run

1. Clone the repository
2. Open `index.html` in any modern browser

Or just [open the live version](https://fernandoalmeid.github.io/FocusTasks/) if GitHub Pages is enabled.

## Project structure

```
FocusTasks/

├── app.js       # All the logic
```

## Why this project?

Built to practice clean vanilla JavaScript, DOM manipulation, and local persistence — skills that transfer directly to any frontend framework.
